# ADC_INTERFACING_I2C_ANALOG_STM32
A complete multi-device I2C application developed for the STM32F407VETx microcontroller. The project demonstrates how to configure a single I2C bus to simultaneously interface with a ANALOG BMP180 Temperature/Pressure sensor, an SSD1306 OLED display, and a standard I2C LCD character display using the STM32 HAL framework.
